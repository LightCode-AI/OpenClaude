# OpenClaude

**中转站掺水的技术分类、可观测痕迹与检测评估**
*Adulteration in API relays: a taxonomy, its observable traces, and an evaluation of detectors*

---

## 这是什么

一份关于第三方 API 中转站**掺水**行为的技术报告。

中转站位于客户端与模型提供方之间，同时是两个连接的端点。协议不提供跨跳完整性——没有可验证的计量凭证，模型身份完全依赖响应中的 `model` 字段自述。因此凡是响应里写的东西都可以改写，凡是客户端无法独立验证的东西都近乎无法被发现。

报告做三件事：

1. 按"被替换的对象"划分出五类掺水：身份、计量、内容、探测规避、性能；
2. 用一个可运行的演示系统 OpenClaude 逐类讲解这些手法的**实现原理**；
3. 把每条可观测痕迹写成可执行的检查，逐条实测，报告哪些仍存在、哪些可以消除。

## 关键结论

| 结论 | 数据 |
|---|---|
| 12 项可观测痕迹检查中，仍有 3 项无法消除 | 全部与"答案是录制样本"有关 |
| 计量一致性问题可由实现纪律消除 | 输出长度变异系数 0.614 → 0.000 |
| 检测器回归 | 8 项可执行检测全部 100 分 |
| 论文签名的"加密验证"只验证格式，不验证来源 | 伪造签名同样通过结构检查 |
| 数字指纹检测依赖统计量选择 | 边缘卡方 0.164（误判），序列排列率 12.1%（336× 基线） |

## 范围与伦理

所述实现仅用于本地授权演示与检测方法研究。演示系统默认回环绑定，不针对任何真实厂商，不破解 TLS，不伪造证书。报告中不包含任何真实服务的地址与凭据。
